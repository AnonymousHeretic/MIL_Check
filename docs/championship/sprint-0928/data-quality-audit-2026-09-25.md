## 6. 후속 조치

1. 적재 시 차수 정규화(`0`→`00`), (계약번호, 차수) 중복 제거, 최신 차수 판정을 정수로.
2. 금액 필드별 의미 확인 전까지 `총계약금액`·`예정가격` 기반 신호를 제품 판정에 쓰지 않는다.
3. 공개수의·입찰공고의 중복 키와 취소·정정 공고를 처리 규칙으로 명시한다.
4. 호환성·단독공급 문서 묶음은 합성 문서 + 공개 공고 첨부로 별도 구축한다([평가셋·라벨 지침](../evaluation-set-and-label-guidelines-v1.md)).

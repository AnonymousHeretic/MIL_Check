# 챔피언십 기술 개발: 단계 0~1

기준일: 2026-09-15. 상태: 설계 개정 및 기존 버전 보존 검사. 새 문서 검토 기능은 후속 구현 대상이다.
이 문서는 대회 제출용 개발계획서가 아니라 저장소 내부의 기술 개발 기준이다.

## 오늘 변경한 방향

핵심 목표는 문서 추출→누락 질문→증빙 대조→담당자 확인→근거 연결 검토보고서로 계약 한 건의 검토를 돕는 것이다.
과거 조항 예측 정확도를 주된 제품 성과로 삼지 않는다. 기존 n-gram은 검색 비교 기준, 로지스틱 회귀는 선택적 과거 경향으로 위치를 조정한다.
제품의 현재 실행 경로·모델·데이터는 보존한다. 모델 재학습이나 신규 흐름을 구현한 것으로 표현하지 않는다.

3. [공통 데이터 계약](contracts.md): 출처·확인·버전·질문·증빙 및 모듈 입출력.
4. [평가 계획](evaluation-plan.md): 외부 학습/내부 독립 시험, 비교군, 업무 효용과 운용 게이트.

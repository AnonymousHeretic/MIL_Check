# 제출 이후 보완사항

제출 기획서는 수정하지 않는다. 이 문서는 제출 이후 레포에 반영한 코드·검증 변경을 기록한다.

## 성능·회귀 검증

- 기존 17개 테스트에 추가 테스트를 더해 총 25개 테스트 통과
- 감사사례 12건 재현: 12/12 (100%)
- AI 자문 계층이 규칙 판정을 바꾸지 않는 불변식 유지
- 시나리오 D의 규칙 통과 및 상위 5건 중 4건 제한경쟁 신호 확인

## 제출 문서와 구현 정합성 보완

- `single_supplier` 규칙 키 불일치 수정
- 제27조 계열을 `post_tender` 추가 규칙팩으로 등록
- 지정·인증 제품을 `designated_product` 추가 규칙팩으로 등록
- 임대차를 `lease` 추가 규칙팩으로 등록
- 세 추가 유형은 필수 증빙이 모두 없으면 자동 승인하지 않고 `NEEDS_EVIDENCE`로 보류
- 전문 기술·자격 용역 자연어 추출 경로 추가
- 내부 행정지연 긴급성의 자유서술 연결 보완
- 입력 정보 부족·유사계약 확신도 미달 시 근거조항·계약방법 추천 보류

## 해석상 주의

추가 유형은 관련 증빙을 요구하는 보수적 규칙 골격이다. 실제 운영 전에는 계약 전문가 검토,
현행 법령 확인, 실데이터 검증을 거쳐 세부 예외와 증빙 목록을 확정해야 한다.

# MIL-Check

공개 계약데이터를 학습한 폐쇄망 군 계약 사전점검 AI 에이전트.

방위사업청 공개 계약데이터 37,595건을 학습한 모델이, 계약 담당자가 결재를 올리기
전에 적용할 근거조항과 계약방법을 확률로 추천하고, 유사계약 가격대·분할발주·업체편중을
탐지하며, 현행 법령 원문을 근거로 연결한다.

**판정은 결정론적 규칙 엔진만이 내린다.** ML 추천과 검색 계층은 참고 신호와 확률만
제시하며 판정을 바꾸지 못한다. 이 불변식은 자동 테스트로 강제된다.

2026 제3차 국방 AI 활용 아이디어 경연대회 출품작.

## 빠른 시작

Python 3.11 이상. 외부 패키지·인터넷·GPU가 필요 없다.

```bash
git clone https://github.com/<사용자명>/milcheck.git
cd milcheck
python demo_app.py
```

브라우저에서 `http://127.0.0.1:8765`를 연다.

```bash
python -m milcheck.cli review examples/sample_small_amount.json   # 단일 검토
python -m milcheck.cli intake "기존 장비랑 호환이 안 돼서요. 4,600만원입니다." --review
python -m milcheck.cli evaluate                                   # 3층 평가 스위트
python -m unittest discover -s tests                              # 17개 테스트
```

내부망에 승인된 OpenAI 호환 LLM 서버(vLLM, llama.cpp server 등)가 있으면
선택적으로 연결할 수 있다. LLM은 입력 문장 이해와 보고서 문장 정리만 담당한다.

```bash
export MILCHECK_LLM_BASE_URL=http://127.0.0.1:8000/v1
export MILCHECK_LLM_MODEL=local-model
python -m milcheck.cli review examples/sample_small_amount.json --llm-mode local
```

## 성능

모든 수치는 `python -m milcheck.cli evaluate`로 재현할 수 있다.
자세한 측정 방법과 한계는 [`docs/metrics.md`](docs/metrics.md) 참조.

| 계층 | 지표 | 값 |
|---|---|---:|
| 근거조항 추천 (19클래스) | Top-1 / Top-3 | 78.1% / 95.4% |
| 계약방법 추천 (6클래스) | Top-1 / Top-2 | 81.0% / 96.0% |
| 폐쇄망 추론 정합성 | sklearn 대비 Top-1 차이 | −0.18%p |
| 근거검색 (구어체 질의 30건) | Recall@1 / MRR | 96.7% / 0.967 |
| 필드추출 (홀드아웃 20건) | 필드 정확도 | 87.9% |
| 감사사례 재현 (12건) | 지적 유형 탐지 | 91.7% |
| 규칙 회귀 (60건) | 잘못된 통과 | 0건 |

공개계약 37,595건 전수 적용 시 표시율: 금액–근거 불일치 0.88%, 분할발주 후보
5.53%, 가격 이상 1.70%, 업체 편중 1.00%. 낮은 표시율은 담당자가 무시하지 않을
수준의 경고량을 뜻한다.

## 구조

```
milcheck/
├── milcheck/
│   ├── rules.py          결정론적 규칙 엔진 — 판정 권한을 가진 유일한 계층
│   ├── linear_model.py   폐쇄망 TF-IDF + 로지스틱 회귀 추론기 (표준 라이브러리)
│   ├── ml.py             근거조항·계약방법 추천, 담당자 제시안과 대조
│   ├── contracts.py      공개계약 검색·가격대·분할발주·편중 탐지
│   ├── retriever.py      법령·감사사례 검색 (BM25 / n-gram / 하이브리드)
│   ├── extract.py        자유서술 → 구조화 필드 추출
│   ├── llm.py            선택적 내부망 LLM 어댑터
│   ├── evaluation.py     3층 평가 스위트
│   └── agent.py          계층 오케스트레이션
├── data/                 규칙·법령색인·모형 가중치·계약 인덱스 (합계 3.5MB)
├── eval/                 평가세트 402건 (자체 60 / 실데이터 300 / 감사 12 / 검색 30)
├── training/             공개망 학습·인덱스 생성·전수 분석 스크립트
├── docs/                 기획서, 성능 문서, 시연 가이드
└── tests/                17개 회귀 테스트
```

`training/` 스크립트는 학습 시에만 필요하며 pandas, scikit-learn을 사용한다.
운영에 필요한 `milcheck/` 패키지는 표준 라이브러리만으로 동작한다.

## 설계 원칙

**학습은 공개망, 추론은 폐쇄망.** 공개망에서 scikit-learn으로 학습한 모델을
희소 가중치 JSON으로 내보내고, 운영 환경에서는 표준 라이브러리만으로 추론한다.
성능 차이는 Top-1 기준 0.18%p로 측정되었다. 군 내부 데이터는 학습에 사용되지 않는다.

**계층별 권한 분리.** 판정은 규칙 엔진, 추천·탐지는 확률과 신호, LLM은 문장 정리.
평가세트 60건 전체에 대해 "AI 계층 탑재 전후의 판정·근거·누락증빙이 동일한가"를
검증하는 테스트가 있다.

**자체 라벨로 성능을 주장하지 않는다.** 평가세트를 라벨 출처 기준 3층으로 분리하고,
자체 작성 라벨의 결과는 회귀 무결성 지표로만 사용한다.

**개인정보를 반입하지 않는다.** 계약 인덱스에서 업체명·사업자등록번호·주소·담당자명을
제외하고 부서명은 SHA-256 별칭으로 치환한다. 자동 테스트로 검증한다.

## 한계

- 초기 규칙팩은 국가계약법상 물품·용역의 소액수의, 경쟁 불성립형, 긴급·보안형만 다룬다
- 분할의 객관적 불가피성(감사원 면책 논리)과 시행규칙 제33조 전자견적 예외를
  아직 반영하지 못한다 (`eval/audit_cases.jsonl`에 기록)
- 가격 이상 탐지는 공개 데이터에 규격·수량이 없어 단가가 아닌 총액 비교다
- 실무자와의 판정 일치도, 실제 검토시간 단축 폭은 아직 측정하지 않았다

## 면책

본 도구는 공개 규정과 공개 계약데이터에 기반한 **사전검토 지원 도구**이며,
계약의 적법성을 확정하거나 계약담당공무원의 최종 판단을 대체하지 않는다.
탐지 결과는 위법 판정이 아니라 담당자 확인이 필요한 후보를 뜻한다.
